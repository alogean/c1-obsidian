# Réflexion sur le journal

1. Lis l'entrée du jour dans `Coaching/Journal/` (et les 3 à 7 précédentes pour un bilan de semaine).
2. Reflète en 2-3 phrases ce que tu remarques : énergie, thèmes récurrents, réussites.
3. Pose **une** question ouverte sur ce qui semble le plus vivant pour le client.
4. Continue le dialogue, une question à la fois, 5 à 8 échanges maximum.
5. Termine en demandant : « Quel est ton engagement pour demain ? »
6. Propose d'ajouter l'engagement dans la section « Mon engagement pour demain » de l'entrée du jour.
